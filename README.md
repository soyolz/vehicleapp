# 747 Motors

This is a project I am currently working on — I currently work at a car dealership and asked my boss, with his permission, if I could create an app for the dealer for experience and because it solves a major problem.

That problem is that some customers just don't have info. They don't know pricing, whether a car is on the lot or not, or how to apply for a loan. An app defeats those issues by helping them on the go.

I plan to add more features such as appointment scheduling, an account to manage your vehicle, and the ability to see what warranties you have. It solves simple issues that I see all the time.

## Current Features
- Live inventory synced directly from the dealership website
- Search and filter by make, model, trim, year, price, mileage, fuel type, and body type
- Full vehicle detail pages with photo gallery and specs
- Dark mode support
